# 📅 Quicknotes 内容日历

一个轻量级 WordPress 内容日历插件，用月历方式查看指定文章类型的发布分布。

有内容的日期会显示数量标记；桌面端鼠标悬浮可查看当天文章列表；移动端点击日期后，会在对应月份日历下方展开当天内容详情。插件支持多月窗口、Ajax 月份导航、分类 / 标签过滤，以及受 WordPress 权限控制的私密内容显示。

> 当前稳定版本：**v1.0.0**

---

## 1. 插件定位

Quicknotes 内容日历最初用于 `quicknotes` 笔记型文章，但数据源没有写死，可选择任意公开的 WordPress `post_type`。

它解决的是一个明确的问题：

> **把 WordPress 内容的发布日期按月可视化，快速查看“哪一天发布过什么内容”。**

当前版本以 WordPress 的 `post_date` 作为日历日期，适合：

- Quicknotes / 工作笔记
- 博客文章归档
- 新闻发布记录
- 内容运营记录
- 其它需要按“发布日期”回顾的自定义文章类型

它不是活动预约或完整事件管理插件，当前不处理独立 `event_date`、重复事件、提醒、Google Calendar / ICS 等能力。

---

## 2. 核心功能

### 📅 多月内容日历

- 默认显示最近 7 个月，可设置为 `1–24` 个月
- 当前月份作为窗口最新月份，向前回溯
- 当前日期高亮
- 顶部显示当前月份范围
- 支持“上一月 / 下一月”Ajax 导航
- 不允许导航到当前月之后的未来月份

### 🔵 日期内容数量标记

按照当天文章数量显示：

- 1 条：`•`
- 2 条：`••`
- 3 条：`•••`
- 4 条及以上：`3+`

数量标记用于快速提示，详细内容在当天列表中查看。

### 💬 当天内容列表

**桌面端：**

```text
鼠标悬浮日期
    ↓
按需加载当天内容
    ↓
显示 Tooltip 列表
```

也支持点击固定打开 Tooltip，点击页面空白处或按 `ESC` 关闭。

**移动端：**

```text
点击有内容的日期
    ↓
在当前月份日历下方展开详情面板
    ↓
点击另一日期 → 切换内容
再次点击当前日期 / 点击空白处 / ESC → 关闭
```

移动端详情面板进入正常文档流，因此不会因日期位于周日 / 周六或月历最后一行而左右越界、覆盖下方内容。

同一日期成功加载后会缓存在当前页面 DOM 中，重复 Hover / 点击不会再次发起 Ajax 请求。

### 🏷 分类 / 标签过滤

后台可以：

1. 选择内容来源 `post_type`
2. 选择该文章类型支持的 taxonomy
3. 勾选一个或多个 term

例如：

```text
post_type = post
taxonomy  = category
terms     = WordPress、开发日志
```

日历只统计符合条件的文章。

### 🔐 Private 内容权限

后台可选择是否包含 `private` 内容。

安全规则：

- 未勾选：只查询 `publish`
- 已勾选：只有当前用户具备对应文章类型的 `read_private_posts` 权限时，才会查询 `private`
- 匿名访客不会因为开启设置而看到私密内容
- 与用户权限相关的 private 统计不写入共享 transient 缓存

## 3. v1.0.0 设计重点

v1.0.0 以“真实站点稳定使用”为目标，没有把插件扩展成大型日程系统，重点完成了以下几类优化。

### 桌面 / 移动交互分离

交互模式只按照当前布局宽度判断：

```text
宽度 > 767px  → Desktop Tooltip / Hover 加载
宽度 ≤ 767px  → Mobile Detail Panel / Click 加载
```

不再使用 `ontouchstart` / `maxTouchPoints` 判断桌面 Hover，从而避免支持触摸的 Windows / 二合一设备被错误排除，解决“第一次 Hover 不加载，点击一次后再次 Hover 才正常”的问题。

### 移动端详情面板

- `<= 767px` 时不使用格子内绝对定位 Tooltip
- 详情显示在对应月份日历下方
- 不会左右越界或覆盖下方模块
- 标题显示完整日期和数量，例如 `2025年8月17日 · 4条内容`
- 长中文、英文、URL 和连续字符支持自动换行
- 当前选中日期保持高亮
- 点击另一日期直接切换
- 月份导航前主动清理详情状态
- 快速连续点击不同日期时，旧 Ajax 请求不会覆盖当前选择

### 缓存与失效机制

公开月度统计使用 WordPress Transient 缓存，并结合 Cache Version 失效机制。

当内容发生以下变化时，会更新缓存版本：

- 新建 / 保存
- 修改发布日期
- 修改分类关系
- 移入 / 恢复回收站
- 删除

因此文章从一个月份改到另一个月份时，不需要逐个猜测并删除旧 transient，旧月份与新月份都会在下一次请求时重新生成正确统计。

包含 private 内容的统计不使用共享 transient，以避免不同用户权限之间产生模糊边界。

### 基础可访问性

- 有内容的日期使用语义化按钮
- 支持 Tab / Enter / Space / ESC
- 使用 `aria-expanded` 表达展开状态
- 页面空白处点击可关闭已打开详情

## 4. 安装

将插件目录上传到：

```text
wp-content/plugins/quicknotes-content-calendar/
```

目录结构：

```text
quicknotes-content-calendar/
├── quicknotes-content-calendar.php
├── README.md
├── includes/
│   ├── class-qncc-plugin.php
│   ├── class-qncc-query-service.php
│   ├── class-qncc-calendar-renderer.php
│   ├── class-qncc-ajax-controller.php
│   └── class-qncc-settings-page.php
└── assets/
    ├── css/
    │   └── quicknotes-calendar.css
    └── js/
        └── quicknotes-calendar.js
```

然后进入：

```text
WordPress 后台
→ 插件
→ 已安装插件
→ Quicknotes 内容日历
→ 启用
```

## 5. 使用方法

### 默认短码

```text
[quicknotes_calendar]
```

将短码放入普通页面、文章或支持 Shortcode 的页面构建器区域即可。

插件会读取后台设置，并生成对应的内容日历。

---

## 6. 后台设置

插件设置页主要包括：

- **Post Type**：日历数据来源
- **月份数量**：显示最近多少个月，范围 `1–24`
- **包含 Private**：仅对具备读取私密内容权限的用户生效
- **Taxonomy**：可选分类法
- **Terms**：可勾选一个或多个分类 / 标签

当更换 Post Type 后，如 taxonomy 选项需要刷新，保存设置后重新进入设置页即可。v1.0.0 暂不为低频后台操作增加额外的动态联动 Ajax。

---

## 7. 数据逻辑

### 日历日期

当前版本使用：

```text
post_date
```

因此文章显示在哪一天，由 WordPress 发布日期决定。

例如：

```text
文章发布日期：2026-10-17
        ↓
日历：2026年10月17日显示内容标记
```

如果未来需要“文章发布日期”和“事件发生日期”分离，应作为新的数据模型设计，而不是直接修改当前 `post_date` 行为。

### 查询边界

日历的月份统计与当天详情使用相同的核心筛选条件：

```text
Post Type
Post Status
Year / Month / Day
Taxonomy
Terms
Current User Capability
```

这保证圆点统计与点击 / Hover 后的详情列表保持一致。

---

## 8. 缓存设计

### 公开内容

公开月度统计可使用 transient，以降低重复查询成本。

缓存键会考虑：

```text
Post Type
Year
Month
Taxonomy
Terms
Cache Version
```

### Cache Version

内容发生变化时不需要扫描并删除所有历史 transient，而是更新版本号：

```text
旧缓存：version = 12
内容更新
新版本：version = 13
```

后续查询自动使用新版本缓存键，旧缓存不再命中，并由 WordPress 按生命周期清理。

### Private 内容

当查询包含 private 内容时，不使用共享 transient。

这是有意的安全取舍：

> **权限相关数据宁可少缓存，也不共享模糊的权限结果。**

## 9. 前端交互说明

### Desktop

```text
Hover
→ 首次 Ajax 加载
→ Tooltip 显示列表
→ 当前 DOM 标记 loaded
→ 后续 Hover 即时显示
```

支持点击固定打开。

### Mobile

```text
Tap 日期
→ 打开日历下方 Detail Panel
→ 首次 Ajax 加载
→ 复用同一份详情 HTML
```

移动端与桌面端共用后端详情接口，不维护两套数据查询逻辑。

### 快速切换保护

用户快速点击多个日期时，每次移动端详情都会记录当前日期标识。较早发出的 Ajax 即使较晚返回，也不会覆盖后来选择的日期内容。

## 12. 已知边界

### 日期语义

当前只认 `post_date`。

例如一篇“10 月 17 日展会”的文章如果 9 月 20 日发布，它会显示在 **9 月 20 日**，而不是 10 月 17 日。

这属于当前产品定义，不是 Bug。

### 页面缓存与 Private

插件本身不会把 private 月度统计写入共享 transient。

但如果“包含 private 的日历页面”被第三方整页缓存、CDN 或缓存插件错误地对匿名用户共享，仍应在站点缓存层正确配置登录态排除规则。

## 14. 开发原则

1. **先保证真实使用稳定，再扩展功能。**
2. **日历只负责按发布日期展示内容，不承担完整事件系统职责。**
3. **优先使用 WordPress 原生能力：WP_Query、权限、Transient、Settings API、Ajax。**
4. **Private 数据宁可少缓存，也不增加模糊的权限边界。**
5. **长期维护优先，不为了功能数量增加复杂度。**
